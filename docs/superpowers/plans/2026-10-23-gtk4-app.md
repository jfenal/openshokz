# GTK4 Settings App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `openshokz-app`, a native GTK4/libadwaita settings window with Device, EQ, Language, and Paired Devices sections on a single scrollable page.

**Architecture:** One `Adw.Application` + `Adw.PreferencesWindow`. Each section is a self-contained `Adw.PreferencesGroup` built in its own module. The app is a thin UI shell: all headset I/O goes through `Gio.Subprocess` calling the `openshokz` CLI. State (active preset) is read from `~/.config/openshokz/state.json` (written by the CLI). Connectivity is checked at startup and on window focus by running `openshokz info --short`.

**Tech Stack:** Python 3.11+, PyGObject (`gi.repository.Gtk`, `gi.repository.Adw`), `libadwaita-1` ≥ 1.4, `openshokz` CLI on `$PATH`.

**Spec:** `docs/superpowers/specs/2026-10-23-gnome-ui-design.md`

**Prerequisite:** `docs/superpowers/plans/2026-10-23-cli-additions.md` must be complete.

## Global Constraints

- `Adw.PreferencesWindow` as the root widget (not `ApplicationWindow`) — standard GNOME settings pattern
- All widget sensitivity set to `False` when headset unreachable; `AdwBanner` shown at top
- EQ apply is immediate (on chip click), no "Apply" button for EQ
- Language Apply button sends all 4 slots in order, same as `openshokz lang`
- Custom preset edit uses `Adw.NavigationPage` (push onto `Adw.NavigationView`), not a dialog
- `openshokz` subprocess calls use `Gio.Subprocess` with `STDOUT_PIPE` to capture output
- Band sliders: range −12 to +12, step 1, value displayed next to slider
- No Flatpak packaging in this plan

## Review Focus

- **Headset disconnects while app is open** — if the user changes something while connected then the headset goes away, the next subprocess call will fail; the app must catch the error, re-show the `AdwBanner`, and re-disable controls without crashing.
- **No `openshokz` on PATH** — app must show an error dialog on startup rather than crashing with `FileNotFoundError`.
- **`state.json` missing (first run)** — no chip is highlighted; the UI must render correctly with no active preset.
- **Custom preset name collision with builtin** — "standard" as a custom name; the CLI handles this (builtin wins), but the UI should not show a duplicate chip.
- **Language reorder then navigate away without applying** — the reordered list should not auto-apply; only the Apply button sends.

### Task 3: EQ section

**Files:**
- Create: `ui/eq_section.py` — `EqSection(Adw.PreferencesGroup)`
- Create: `ui/edit_preset_page.py` — `EditPresetPage(Adw.NavigationPage)`
- Modify: `ui/window.py` — add `EqSection`, connect navigation

**Interfaces:**
- Consumes: `run_openshokz("eq", "list", "--json")`, `_load_state()`, `run_openshokz("eq", name)`
- Produces: `EqSection` with chip row and `+ Add` button; `refresh(connected)` method

- [ ] **Step 1: Implement `EqSection`**

On init: call `run_openshokz("eq", "list", "--json")`, parse JSON, build a horizontal `Gtk.FlowBox` of `Gtk.ToggleButton` chips. Read `_load_state()` to set the active chip. Each chip click calls `run_openshokz("eq", preset_arg)`, on success updates active chip and re-saves state.

`+ Add` chip opens `EditPresetPage` (push onto NavigationView) with empty name and flat bands.

Long-press or pencil icon on a custom chip opens `EditPresetPage` pre-filled.

`refresh(connected)` sets `sensitive` on all chips.

- [ ] **Step 2: Implement `EditPresetPage`**

`Adw.NavigationPage` with `Adw.PreferencesGroup` containing:
- `Adw.EntryRow` for name
- 7 `Adw.ActionRow`s each with a `Gtk.Scale` (range −12..12, digits 0) and a label showing the current value
- "Apply & Save" `AdwButtonRow` → calls `run_openshokz("eq", "preset", "add", name, *bands)` then `run_openshokz("eq", name)`, then pops nav page
- "Delete" `AdwButtonRow` (destructive, hidden for new presets) → calls `run_openshokz("eq", "preset", "delete", name)`, then pops

- [ ] **Step 3: Smoke test**

Run: `python3 -I openshokz_app.py`

- [ ] **Step 1: Implement `LanguageSection`**

`refresh(connected)` sets `sensitive` on rows and Apply button.
